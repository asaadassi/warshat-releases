# ورشات (Warshat by Shihab App)

تطبيق أندرويد للمهندس المنفذ لمتابعة مشاريعه الإنشائية: الدفعات الواردة من العملاء، والمصروف على الورشات والمشتريات مع صور الفواتير، وبنود المتابعة الفنية بنسبة إنجاز، وتقرير PDF للعميل.

هذا المستودع للإصدارات فقط: ملفات APK الموقّعة وبصماتها وتوقيعاتها، ومنه يجلب التطبيق تحديثاته. الكود في مستودع خاص.

- اسم الملف: `Warshat-android-<الإصدار>.apk` مع `.sig` (توقيع الناشر).
- الوسم: `v<الإصدار>`.
